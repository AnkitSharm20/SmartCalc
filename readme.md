✨ About

SmartCalc is a modern calculator application designed to go beyond the traditional calculator.

The project focuses on creating a clean, fast, accessible and extensible calculation experience that can eventually grow into a complete calculation platform across:

- 🌐 Web
- 📱 Mobile
- 💻 Desktop

SmartCalc is currently under active development.

The project is being built as both a BCA academic project and a portfolio project, with an emphasis on practical programming, UI/UX design, accessibility, software architecture and real-world development practices.

---

🏗️ Architecture

SmartCalc is being designed with separation between the user interface and calculation logic.

                 ┌─────────────────────┐
                 │      SmartCalc      │
                 └──────────┬──────────┘
                            │
              ┌─────────────┴─────────────┐
              │                           │
              ▼                           ▼
       ┌──────────────┐           ┌──────────────┐
       │   UI Layer   │           │ Logic Layer  │
       └──────┬───────┘           └──────┬───────┘
              │                          │
       ┌──────┴───────┐          ┌───────┴────────┐
       │ Components   │          │ Calculator     │
       │ Controls     │          │ Parser         │
       │ Themes       │          │ Operations     │
       └──────────────┘          │ Validation     │
                                 └────────────────┘

This approach makes it easier to expand SmartCalc to additional platforms in the future.

⚙️ Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/SmartCalc.git

Enter the project directory:

cd SmartCalc

Then open:

index.html

in your browser.

For local development, a simple development server such as VS Code Live Server can also be used.
